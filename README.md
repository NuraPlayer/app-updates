# Nura Player

[Nura Player](https://nuraplayer.uk) is an IPTV player for Android TV, Google TV and Formuler boxes, with a simpler version for phones and tablets. You bring your own M3U or Xtream playlist; Nura does not provide, host or sell any content.

- **Website and downloads:** https://nuraplayer.uk
- **Help and guides:** https://nuraplayer.uk/help/
- **Discord:** https://discord.gg/Xx9cJNRuXG

This repository holds the release manifests and APK files that the Nura app uses to update itself. See the [Releases](https://github.com/NuraPlayer/app-updates/releases) page for what changed in each version.
